# 示例复现输入模板

以下提示依据现有示例整理，便于理解应提供哪些资料，不是原始对话的逐字运行记录。不同模型及材料会产生不同结果，不承诺逐字复现现有Word。

## 应准备的资料

1. 本人合法持有的汽车技术工作页材料，明确页码和版本。
2. 培养层次、课程标准、学生基础与拟用学时。
3. 校内设备、惰性训练件、隔离线束与模拟台架条件。
4. 实车操作如确有需要，应另行提供适配手册、设备说明及人员授权要求。
5. Word排版模板、作者、备注及成果命名要求。

## 可直接使用的输入

```text
请使用 $develop-vocational-learning-tasks，依据我提供的汽车技术学习领域9资料，开发舒适与安全系统服务学习任务。

以提供的第5—20页为资料范围，设计四个任务：
1. 事故后乘员保护系统检查与修复方案，建议16学时；
2. 座椅占用识别间歇故障定位，建议8学时；
3. 空调制冷性能诊断与维护交付，建议24学时；
4. 门锁与车窗联动失效的共因诊断，建议12学时。

每个任务按十部分编写：学习情境、学习目标、任务要求、任务分工、获取信息、制定计划、任务实施、检查交付、评价反思、相关知识与技术资料。

获取信息到检查交付主要通过引导问题组织，依据学生基础逐步提高认知要求。提供实际操作与个人记录，保留有效原题和图文对应。系统编写相关理论，包含概念、原理、方法、例题、适用条件和常见错误。

另写教师参考稿，包括目标、问题、知识与证据对应，逐题参考、操作观察点、评分依据和课前待核条件。技术验收与学习评价区分处理。

将原题给定、厂家核实、教学模拟和现场实测分开标明。缺页、未核实参数和车型差异如实说明；保留来源，不编造原始图样。SRS采用教师确认的惰性件和隔离模拟条件，真实作业按授权与适配资料确定。

生成学生工作活页和教师参考两份Word，作者及备注设为蔡跃。按指定模板排版并检查分页。
```

班级层次、实际车型、设备和手册版本在现有材料中尚需确认，不能从示例学时反推为已经确定的课程条件。
