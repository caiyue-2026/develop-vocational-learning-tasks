# 环境说明

## 项目组成

技能由Markdown规则与参考资料、JSON字段模板、界面元数据、可选Python结构校核脚本组成。它不包含大模型权重、在线推理服务、独立应用界面或自动购买API的功能。

## 能力条件

| 功能 | 所需条件 | 缺少时的处理 |
|---|---|---|
| 执行技能 | 能读取完整技能目录并遵循规则的AI助手 | 手动提供规则仅作辅助，不声称完成安装 |
| 生成内容 | 用户自行使用的模型或AI客户端 | 项目不提供免费算力或模型服务 |
| 核实最新技术 | 可访问权威资料的检索或用户提供材料 | 明确待核，避免冒充已核实依据 |
| Word生成 | 可用DOCX工具及文件保存权限 | 可先输出结构化文本，说明未完成文件生成 |
| Word排版检查 | 可用渲染器及中文字体 | 字体替换和分页需另行检查 |
| 精确图样 | 原始图纸或可核查的绘图工具 | 不用装饰图替代可执行技术图样 |
| 结构校核 | Python 3.8或以上及标准库 | 不影响人工使用技能正文 |

Python版本下限依据脚本语法及标准库需求制定，本次未逐一在每个Python版本上测试。校核脚本不依赖额外第三方包。模型调用、Word制作和检索的费用或权限由用户选用的环境决定。

## 文件与字体

默认字体为黑体、宋体及仿宋；设备未安装时可能替换并改变分页。Word文件建议用具有相应字体的桌面软件查看。不要通过改扩展名把Markdown文件当作Word文件。

## 限制

结构校核不能检验图纸正确性、参数适用性、答案科学性、学生操作熟练度或真实教学效果。汽车SRS、空调制冷剂和门控等示例只能在所列教学与授权条件下使用，具体操作由适配资料和教师审核决定。
