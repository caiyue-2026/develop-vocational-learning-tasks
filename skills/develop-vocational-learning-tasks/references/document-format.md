# 文档格式与交付

用户本次明确格式和模板优先。未指定时采用下列格式，适用于技能运行后生成的 Word。当前技能包中的 Markdown 模板不必转为空白 Word。

| 对象 | 默认格式 |
|---|---|
| 页面 | A4 纵向，页边距未指定时各 2.5 cm，考虑装订及书写 |
| 全文 | 黑色，清除主题色 |
| 总标题 | 黑体二号 22 pt，居中，Title 样式，不额外加粗 |
| 一级标题 | 黑体三号 16 pt，Heading 1，不额外加粗 |
| 二级标题 | 黑体四号 14 pt，Heading 2，不额外加粗 |
| 三级标题 | 宋体小四 12 pt，Heading 3，不加粗 |
| 标题段落 | 段前、段后各 0.5 倍行距，与后文保持同页 |
| 正文 | 仿宋小四 12 pt，两端对齐，首行 2 字符，1.5 倍行距 |
| 表名及表内文字 | 五号 10.5 pt；表名在表上方，编号采用 1.1 形式 |
| 图名 | 五号 10.5 pt；图下方，编号采用 1-1 形式 |
| 属性 | 作者及备注 comments 属性均设为蔡跃，清除默认自动生成说明 |

分别设置中文、西文字体；首行采用字符缩进或约 24 pt。标题半行间距优先采用 Word 行单位，库不支持时依据实际段落行高换算并渲染核查，不设成半磅。引导问题、填表指令及记录区可以不做首行缩进。表格按内容设置列宽、内边距和对齐，不能用固定行高裁切内容。

每个任务能独立取用，设置任务编号及任务内页码，汇总整本时兼顾总页码。评价表独立成页，必要检查表按使用需要单独成页，长表重复表头。理论部分与任务采用同一编号体系。

默认生成《任务名称学习任务工作活页.docx》和《任务名称学习任务教师参考.docx》。用户只要学生稿或其他格式时遵从，不自动交付内部日志。学生版最后的实质部分为相关知识与技术资料，参考资料可置于该部分末尾。

输出前使用当前环境 documents 技能生成、渲染、逐页查看并修订，检查字体、标题样式、图表、填写空间、分页及属性。正文和表单保持可编辑。精确图样优先使用 CAD、SVG 等可核查方式，不能用生成式图片充当尺寸、公差或线路依据。无法完成文件生成或渲染时如实说明，不声称执行了未做的检查。

遵循当前环境的持久保存和文件链接规范。
