# 理论知识编写

## 核心要求

将相关知识与技术资料写成结构完整、可自主学习的教材正文。该部分允许较多页数，应在规划时留足篇幅。不能只给目录、知识点清单、网页链接或工作步骤摘要。

## 建立知识结构

从目标和引导问题反查必要知识，再按知识关系组织，按专业特点覆盖以下内容：

1. 基本概念与术语：定义、特征、相近概念的差异及使用情境。
2. 对象与构成：结构、要素、功能及相互关系。
3. 基本原理：因果关系、工作机制和规则，解释为什么。
4. 方法与程序：适用条件、步骤、选择依据和局限。
5. 计算与数据：公式、变量、单位、前提、处理过程和结果判读。
6. 工艺与规范：质量、关键参数、检验方法及标准依据。
7. 常见问题：易混点、典型错误、成因及修正方法。
8. 典型例题与迁移：用相似但不同于学生任务的条件展示推理和应用。

以上为覆盖检查，不必强设八个小节。商贸服务类可采用需求分析、沟通原理、流程规则和服务质量等知识组织，不强套工程公式。

## 正文深度

使用 K1、K1.1 等编号。以连续段落解释概念、原理和方法，再配必要图表、计算与例题。每个核心主题交代是什么、为何适用、如何使用、适用条件及边界，无需机械重复四个标题。

图表解释其含义，公式说明符号与单位，例题展示完整过程和结果解释。适当说明知识用于任务中哪些判断，并与 Q 编号相互参照。短提示置于问题附近；系统解释在末部分。保留必要重复提醒，避免相同长段落多次出现。

## 深度示例

电脑组装中的硬件兼容性知识至少解释机械安装、电气连接、接口与系统支持的区别；处理器、主板及固件支持的关系；插槽相同为何仍需核查支持列表；内存类型、容量和运行条件；存储接口及资源限制；供电、散热和空间要求；如何根据厂家说明形成核验结论。

实际正文应展开上述知识，并提供使用另一组教学条件的完整核验例题。这里不预设任何现售型号及参数，实际引用均需核实。不要把覆盖要求直接复制成最终教材的短句清单。

## 技术资料与来源

把规格表、图例、检验依据、工艺卡示例与正文配合使用。标准记录名称、编号、版本、条款和适用条件；设备资料记录厂家、型号、版本；网页记录机构、标题、URL及查询日期。优先原始来源，适度引用并自行解释，不长篇复制受版权保护资料。

已提供资料不等于现行有效。无法访问或核实的材料不能声称已核实。缺少关键条件时在教师参考稿列补充需求，不伪造图纸、标准或数据。

## 篇幅与验收

普通任务按约 4—8 页 A4 理论正文规划，复杂任务约 8—15 页或更多，依知识完整性调整。这是编排建议，不以页数替代质量。用户有总页数限制时说明重要取舍，服从本次要求。

检查理论能否支持每个必要问题，是否解释关键判断依据，是否有必要例题和结果分析。成品中不得用待补充、略、同上、见网络资料或省略号代替正文。仅要提纲时可交提纲，但不得称为完整理论内容。
